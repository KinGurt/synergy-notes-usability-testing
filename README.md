# Юзабилити-тестирование Synergy Notes

Комплект предназначен для проведения реального пилотного юзабилити-тестирования мобильного приложения Synergy Notes и оформления кейса №5 практики.

## Важно
Материалы содержат методику, сценарии, приоритеты улучшений и поля для внесения результатов. Числовые показатели, фактические замечания и сведения об участниках заполняются только после реальных сессий с 3–5 участниками. Не следует выдавать шаблонные значения за результаты исследования.

## Порядок работы
1. Найдите 3–5 участников: студентов или сотрудников, которые пользуются заметками на смартфоне.
2. Ознакомьте каждого с информационным сообщением и получите согласие.
3. Проведите сессию по сценарию.
4. Зафиксируйте наблюдения в форме.
5. Сведите данные в CSV.
6. Заполните слайды по outline и сохраните в PDF/PPTX.

## Модельный пример
Файл `data/results-modelled.csv` и диаграммы с пометкой `modelled` содержат синтетические учебные данные. Они подходят только для демонстрации оформления и не являются результатами реального исследования.
